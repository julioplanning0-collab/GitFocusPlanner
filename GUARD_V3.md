## 🎯 TYPES V3 RÉFÉRENCE

### TaskV3 (OBLIGATOIRE)
```python
class TaskV3(TypedDict):
    minuteOffset: int        # Minutes from planningStartTime (REQUIRED)
    duration: int            # Duration in minutes
    type: str                # POMODORO, PAUSE, CALIN, CLOPE, PLANNED
    taskId: str              # Original task ID from CSV
    taskName: str            # Display name
    isFixed: bool            # true = non-draggable
    pomodoroIndex: int       # Optional: 1, 2, 3... (POMODORO only)
    pomodoroTotal: int       # Optional: total for this task
    autoGenerated: bool      # Optional: true for calins/clopes
```

### Obstacle
```python
class Obstacle(TypedDict):
    startMinute: int         # Start time (minutes from planningStart)
    endMinute: int           # End time (minutes from planningStart)
    type: str                # Always 'temps_mort'
    originalData: dict       # Original CSV data
```

### Timeline
```python
class Timeline(TypedDict):
    planningStartTime: str   # ISO datetime
    tasks: List[TaskV3]      # All tasks with minuteOffsets
    obstacles: List[Obstacle]  # All obstacles
```
