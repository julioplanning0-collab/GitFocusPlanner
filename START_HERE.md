## 🎯 Qu'est-ce Que C'est?

Application web de **planning Pomodoro intelligent** avec:

- ✅ **Apprentissage automatique** - Le système apprend vos habitudes
- ✅ **Scoring 4 critères** - Sélection automatique top 10 tâches
- ✅ **Interface moderne** - Design responsive + code couleur
- ✅ **28 endpoints API** - Architecture REST complète
- ✅ **Protection données** - Écriture atomique partout

---

## 🧠 Comment Ça Marche?

1. **Vous sélectionnez** 2-3 tâches de travail (Pomodoro)
2. **Le système calcule** automatiquement les meilleures tâches récurrentes
3. **Planning généré** avec alternance stricte travail ↔ pause
4. **Export CSV** pour app Android + enregistrement historique
5. **Apprentissage** - Plus vous l'utilisez, mieux il connaît vos habitudes
