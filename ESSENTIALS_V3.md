## 🎯 Concept Central : Timeline Linéaire

**Principe** : Temps RELATIF en minutes depuis `planningStartTime`

```
Timeline = axe en minutes
  0 min  → planningStartTime (ex: 14:00 aujourd'hui)
  25 min → 14:25
  720 min → 02:00 (jour suivant)
```

**Avantages** :
- Arithmétique simple (additions entières)
- Multi-jours natif
- Drag & drop facile (déplacement sur axe)
- Conversion temps absolu UNIQUEMENT pour affichage final

**Point zéro** : maintenant + 15min arrondi au multiple de 5 supérieur (13:07 → 13:25)

## 🏗️ Architecture 2-Step (CRITIQUE)

**RÈGLE D'OR** : Séparer construction séquence du calcul des heures

```javascript
// ÉTAPE 1 : ORDERING (construction liste ordonnée)
// → Construire [Pomodoro, Respiration, Câlin, Pomodoro, ...]
// → SANS minuteOffset (ou =0)
const orderedTasks = alternatePomodoresRespiration(pomodoros, respirations);
insertCalins(orderedTasks);  // Every 2 respirations
insertClopes(orderedTasks);  // Cumulative duration

// ÉTAPE 2 : TIME CALCULATION (calcul minuteOffsets)
// → Calculer minuteOffset pour chaque tâche séquentiellement
rebuildTimeline(orderedTasks, obstacles);
// → Résultat : timeline.tasks avec minuteOffsets corrects
```

**Fonction centrale** : `rebuildTimeline()`
- Recalcule TOUS les minuteOffsets
- Appelée après CHAQUE modification timeline
- Parcourt séquentiellement, saute obstacles

## 🔄 Fonctions Essentielles Frontend

### Conversion Temps
```javascript
// Date → minutes relatives
dateTimeToMinutes(dateTime, planningStart) 
  → (dateTime - planningStart) / 60000  // milliseconds to minutes

// Minutes relatives → Date
minutesToDateTime(minutes, planningStart)
  → new Date(planningStart.getTime() + minutes * 60000)

// temps_morts CSV → Obstacles
convertTempsMortsToLinear(tempsMorts, planningStart)
  → tempsMorts.map(tm => ({
      startMinute: dateTimeToMinutes(tm.debut),
      endMinute: dateTimeToMinutes(tm.fin),
      type: 'temps_mort',
      originalData: tm
    }))
```

### Construction Timeline
```javascript
// STEP 1: ORDERING
buildPomodoroList(selectedTasks)
  → selectedTasks.flatMap(task => 
      Array(nbPomos).fill().map((_, i) => ({
        type: 'POMODORO',
        duration: 25,
        pomodoroIndex: i + 1,
        pomodoroTotal: nbPomos,
        minuteOffset: 0  // Will be calculated in step 2
      }))
    )

buildRespirationList(selections)
  → selections.flatMap(sel => Array(sel.count).fill(sel.task))

alternatePomodoresRespiration(pomodoros, respirations)
  → cycle through respirations for each pomodoro
  → [P1, R1, P2, R2, P3, R1, P4, R2, ...]

insertCalins(tasks)
  → Every 2 respirations, insert CALIN (5min)
  → In-place modification

insertClopes(tasks)
  → Track cumulative duration
  → When >= 240min, insert CLOPE (25min) + reset counter
  → In-place modification

// STEP 2: TIME CALCULATION
rebuildTimeline(tasks, obstacles)
  → currentMinute = 0
  → for each task:
      nextFreeSlot = findNextFreeSlot(currentMinute, task.duration, obstacles)
      task.minuteOffset = nextFreeSlot
      currentMinute = nextFreeSlot + task.duration

findNextFreeSlot(start, duration, obstacles)
  → while (hasCollision(start, start+duration, obstacles)):
      start = nextObstacleEnd
  → return start

hasCollision(start, end, obstacles)
  → obstacles.some(obs => start < obs.endMinute && end > obs.startMinute)
```

## 🔧 Gestion Collisions & Cas Spéciaux

### Priorités
1. **Temps mort** (absolue) - JAMAIS déplacé
2. **Tâche planifiée FIXE** (haute) - Replace Pomodoro closest to requested time
3. **Tâche planifiée FLEXIBLE** (moyenne) - Can shift if collision
4. **Pomodoro/Respiration** (basse) - Fill remaining slots

### Algorithme Collision
```javascript
// Si tâche planifiée collision avec obstacle
if (hasCollision(plannedTask, obstacles)) {
  // 1. Try shift forward
  nextSlot = findNextFreeSlot(requestedTime, duration, obstacles);
  if (nextSlot - requestedTime <= 60) {  // Within 1h
    place at nextSlot;
  } else {
    // 2. Try shift backward
    prevSlot = findPreviousFreeSlot(requestedTime, duration, obstacles);
    if (requestedTime - prevSlot <= 60) {  // Within 1h
      place at prevSlot;
    } else {
      // 3. Give up, place at next available
      place at nextSlot;
      mark as significantly rescheduled;
    }
  }
}
```
