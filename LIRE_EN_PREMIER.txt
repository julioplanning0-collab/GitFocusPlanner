┌──────────────────────────────────────────────────────────────┐
│  SYSTÈME D'APPRENTISSAGE INTELLIGENT                         │
└──────────────────────────────────────────────────────────────┘

  Le système s'améliore automatiquement avec le temps!

  Scoring 4 critères (0-100 points):
    • 50% Récurrence DUE (urgence - tâches en retard)
    • 20% Fréquence jour semaine (habitudes - lundi → arrosage)
    • 15% Fréquence globale (popularité - tâches souvent utilisées)
    • 15% Récence (actualité - tâches récentes)

  Évolution:
    Mois 1  → Scoring basé surtout sur urgence
    Mois 2  → Détection patterns simples
    Mois 6  → Patterns clairs (ex: "Arroser plantes" → 80% lundi 08:00)
    Année 1 → Système très précis, adapté à vos habitudes


┌──────────────────────────────────────────────────────────────┐
│  PROBLÈMES COURANTS                                          │

  Port 5000 déjà utilisé:
    → Fermer autres serveurs Flask/Python sur port 5000
    → Ou changer PORT dans webapp\config.py

  Interface ne charge pas:
    → Vérifier que le serveur est démarré (voir console)
    → Faire Ctrl+F5 pour forcer rechargement cache navigateur

  Fichiers CSV manquants:
    → Lancer: python scripts\verify.py
    → Vérifier que prod_data/ contient tous les CSV requis
